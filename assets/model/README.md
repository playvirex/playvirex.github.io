# 3D 모델 넣는 곳

여기에 `.glb` 파일을 올리면 게임이 그림 대신 그 모델을 씁니다.

파일 이름을 아래와 똑같이 맞춰 주세요.

| 파일 이름 | 무엇 |
|---|---|
| `body.glb` | 숙주의 몸 (남성) |
| `body_f.glb` | 숙주의 몸 (여성) |
| `body_old.glb` | 숙주의 몸 (노년) |
| `nasal.glb` | 비강·인두 |
| `phar.glb` | 편도·후두 |
| `bron.glb` | 기관·기관지 |
| `alv.glb` | 폐포 |
| `blood.glb` | 혈류(심장) |
| `gut.glb` | 위·소장 |
| `liver.glb` | 간 |
| `cns.glb` | 중추신경(뇌) |

## 블렌더에서 내보낼 때

- `파일 > 내보내기 > glTF 2.0 (.glb)`
- 형식은 **glTF Binary (.glb)** 한 덩어리로
- 원점을 모델 가운데에 두고, 머리가 +Y(위)를 보게
- 폴리곤은 5만 개 이하면 폰에서도 잘 돕니다
- 재질은 간단할수록 좋습니다. 색은 게임이 감염 상태에 맞춰 덮어씁니다
